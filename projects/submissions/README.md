# 📥 Project Submissions Drop-Box

Upload your MakeCode Arcade `.png` project cartridge files here!

1. Click **Add file → Upload files** in the top-right corner.
2. Drag your `.png` file downloaded from [arcade.makecode.com](https://arcade.makecode.com) into the upload area.
3. Name your file with your safe team slug (example: `blue-otter-my-game.png` — **no full last names!**).
4. Click **Commit changes**.

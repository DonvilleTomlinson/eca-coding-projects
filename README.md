## 💾 Step 1: Save Your Project from MakeCode Arcade

In [MakeCode Arcade](https://arcade.makecode.com), you can save your project in two ways:

### Option A: Download a `.png` Game Cartridge (Recommended)
1. At the bottom of the MakeCode Arcade screen, type a name for your game using your **team slug** (for example: `blue-otter-pizza-chase`).
2. Click the **Save** (floppy disk 💾) button next to the project name.
3. MakeCode will download a `.png` image file (like `arcade-blue-otter-pizza-chase.png`).
   > 💡 *Cool fact:* MakeCode hides your entire game program inside that `.png` picture!

### Option B: Create a Playable Share Link
1. Click the **Share** button near the top-left of MakeCode Arcade.
2. Confirm the project name and click **Publish project**.
3. Click **Copy** to copy your playable link (it looks like `https://arcade.makecode.com/S...`).

## 🚀 Step 2: Upload Your Project to GitHub

Choose whichever method your teacher asks you to use today:

### Method 1: Upload to a Folder (Direct File Upload)
1. Click on the folder for today's week below (or open [`projects/submissions/`](projects/submissions/)).
2. In the top-right corner of the file list, click **Add file** → **Upload files**.
3. Drag and drop your MakeCode `.png` cartridge file (or `.uf2` / `.mkcd` file) into the upload box.
4. At the bottom under **Commit changes**, write a short note like `Add blue-otter space dodge game` and click the green **Commit changes** (or **Propose changes**) button.

### Method 2: Submit via the Class Issue Drop-Box
1. Click [**Submit a MakeCode Project**](../../issues/new?template=submit-makecode-project.yml) (or click the **Issues** tab at the top → **New issue**).
2. Fill in your **Team / Student Slug** and **Game Title**.
3. Drag and drop your `.png` cartridge file into the box **and/or** paste your MakeCode Share Link.
4. Click **Create**!

---

## 🔄 Step 3: How to Open or Play a Classmate's Project

Want to playtest a classmate's game or continue working on your own game on a different Chromebook?

1. Click on the `.png` project file in this repository and download it to your computer.
2. Open [https://arcade.makecode.com](https://arcade.makecode.com).
3. **Drag and drop** the downloaded `.png` file directly onto the MakeCode Arcade home screen (or click **Import** → **Import File...**).
4. Your full blocks, JavaScript, and Python code will open right up!
